# 🚀 Portfolio Professionnel - Seif Ghozlani

Portfolio web moderne et interactif de **Seif Ghozlani**, Élève Ingénieur en Informatique à l'École Polytechnique de Sousse (Systèmes Intelligents, Logiciel & Embarqué IoT).

## ✨ Fonctionnalités
- 🌐 **Bilingue (FR / EN)** avec bascule instantanée sans rechargement
- ⚡ **Effet Typewriter dynamique** sur les rôles techniques
- 🏆 **Section Distinctions** mettant en avant la mention honorable à l'**ICPC 2026**
- 🏭 **Timeline Expérience Leoni** détaillée avec technologies et métriques
- 🛠️ **Filtres de compétences & projets** interactifs
- 🔍 **Modale d'inspection de projet** détaillée
- 📋 **Copie rapide presse-papiers** pour l'email et le téléphone avec toasts animés
- 📱 **100% Responsive** (mobile, tablette, desktop) et optimisé pour l'impression / export CV
